# Learn Music

A browser-based learning environment that teaches music composition and production together.

The application grows from a constrained teaching interface into a compact music-production workspace. The first prototype focuses on pulse, rhythm, sequencing, transport, and immediate musical feedback.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run typecheck
npm run build
```

GitHub Pages deployment is handled by `.github/workflows/pages.yml`.
